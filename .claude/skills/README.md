# スキル（Claude用の作業手順書）

Claude Code は、このフォルダのスキルを読んでから作業する。人が呼び出す必要はなく、
依頼の内容に合うスキルが自動で読まれる。

## 共通スキル（3つのアプリで同じものを置いている）

| スキル | いつ効くか |
|---|---|
| `shikumika` | 仕組み化の相談を受けたとき。何を聞き、どこまで作るかの判断 |
| `supabase-migration` | DBのテーブル・列を変えるとき |
| `line-notify` | LINE通知・定時実行を足すとき |
| `release-check` | コミット・pushの前の自己点検と、報告の書き方 |
| `documents` | 見積書・請求書・シフト表など書類やファイルを作るとき |

## このリポジトリ専用（焼肉がみやアプリ）

| スキル | いつ効くか |
|---|---|
| `gamiya-app` | このリポジトリで手を動かすとき全般。営業日は朝5時区切り、hooks/lib/画面の3層、Realtime、予約表とシフトの数え方、globals.cssで作る見た目、Whisperの呼び方 |

## PDF・Excel・Wordについて

ファイルを作る・読む部分は、Claudeに標準で入っている `pdf` / `xlsx` / `docx` スキルが受け持つ。
リポジトリに置く必要はない。使い分けは共通スキル `documents` にある。

## 共通スキルの直し方

共通スキルは良心アプリのリポジトリ（`yoshiyuki-cpu/-`）を正とする。直したら、こことラウンジケリー
（`lounge-kelly`）にも同じ内容をコピーする。Claudeに「共通スキルを3つのリポジトリに揃えて」と言えばよい。
