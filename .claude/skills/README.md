# スキル（Claude用の作業手順書）

Claude Code は、このフォルダのスキルを読んでから作業する。人が呼び出す必要はなく、
依頼の内容に合うスキルが自動で読まれる。

## 共通スキル（3つのアプリで同じものを置いている）

| スキル | いつ効くか |
|---|---|
| `shikumika` | 仕組み化の相談を受けたとき。何を聞き、どこまで作るかの判断 |
| `supabase-migration` | DBのテーブル・列を変えるとき |
| `line-notify` | LINE通知・定時実行を足すとき |
| `release-check` | コミット・pushの前の自己点検と、報告の書き方 |

## このリポジトリ専用のスキル

まだ無い。焼肉がみやアプリ固有の決まりごと（営業日は朝5時区切り、hooks/でデータ取得を分ける、
LINEは友だち全員へのbroadcast、チェック表・予約表・シフト・タイムカードの関係）は、
次に整理してここに置く。

## 共通スキルの直し方

共通スキルは良心アプリのリポジトリ（`yoshiyuki-cpu/-`）を正とする。直したら、こことラウンジケリー
（`lounge-kelly`）にも同じ内容をコピーする。Claudeに「共通スキルを3つのリポジトリに揃えて」と言えばよい。
